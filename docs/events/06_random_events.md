# 事件库 06：随机事件池（1948–2006，可反复发生）

> [!NOTE]
> 本文件收录**随机事件**（编号 R-），格式遵循 [README.md](README.md) 第6节。随机事件**会不会发生是纯随机的**，只受时代和最基本的存在性前提限制；但**后果随国家状态缩放**，所以和玩家此前的决策仍然相关。所有数值均为示意，需要通过原型校准。

---

## 0. 使用说明

### 0.1 和固定事件的分工
- 固定事件（E-）讲“这个国家在这个时刻必然面对的问题”；随机事件（R-）讲“治理一个国家时总会碰上的事”。
- 时代文件中已有的通用事件（E-G01-xx 至 E-G05-xx）由数值阈值触发，**本文件不重复它们**。与之相近的随机事件（如黑市、渗透、换俘）在条目中注明了分工：时代通用事件管“结构性的潮流”，随机事件管“单起的、偶发的个案”。
- 随机事件的力度整体比锚点事件小：大部分为**小、中**力度；只有地震、空难等少数事件可以达到**大**力度。暴行类事件不进入随机池。

### 0.2 频率预算（依据 README 第6.3节）

| 规则 | 数值（示意） |
|---|---|
| 平时随机事件的平均频率 | 每个游戏月约1条 |
| 每月上限 | 2条 |
| 危机期间 | 随机事件暂停，只保留安全类和灾害类（见0.4） |
| 被动事件比例 | 约40%（本文件 59 条中被动 25 条，约42%） |
| 小事件 | 标【小】的抉择事件可以交给顾问自动处理，顾问按玩家的立场走廊选择 |

**每月结算流程**：
1. **筛选**：去掉不在时代范围、前提不满足、处在冷却中、已达上限的事件；危机期间再去掉安全类和灾害类以外的事件。
2. **归一**：把剩余候选的基础概率相加，记为 S。本文件全部事件可用时 S 约为每月110%（季节性事件按全年平均折算）。若 S 偏离目标值1.0（即每月期望1条），所有候选的概率统一乘以 1.0/S。这样，可用事件较少的早期时代不会冷清，可用事件多的后期也不会过密。
3. **掷骰**：每条候选独立掷骰。
4. **同类限制**：同一类别每月最多1条（不会同月出现两场罢工）。
5. **上限**：命中超过2条时，按 安全类 > 大力度 > 被动 > 其他 的顺序保留2条，其余**作废，不顺延**，避免积压。
6. **季节性事件**：条目写“只在某些月份掷骰”的，概率只在这些月份生效，不参与其他月份的归一计算。

### 0.3 随机槽位的抽取规则

| 槽位 | 抽取范围 | 权重 |
|---|---|---|
| {区} | 当前存在的区（6个固定区 + 存在的动态区），事件可以另行限定子集 | **灾害、社会、经济类**：按区人口加权；**安全类**：权重 = (100 − 安全[区]) × 边境系数（边境区和动态区为1，腹地为0.2） |
| {城镇} / {城市} / {设施} | 由已抽出的 {区} 决定，从该区的关键地点表中抽 | 等权 |
| {群体} | 米兹拉希、俄裔（1990年后）、埃塞俄比亚裔（1985年后）、阿拉伯人、德鲁兹人、贝都因人、哈雷迪等 | 权重 = 疏离度（或 100 − 国家认同度），即越不满的群体越容易成为主角 |
| {部长} | 当前内阁中的AI部长（不含玩家本人） | 权重 = 野心 + (100 − 忠诚)；丑闻类再加上 (100 − 能力)/2 |
| {政党} | 当前联合政府中的盟党 | 权重 = 100 − 盟党满意度[政党] |
| {国家} | 本时代存在的国家，事件给出候选表 | 按事件给出的权重；安全类按 政权敌意[国] 加权 |
| {派系} | 本时代存在的巴勒斯坦或黎巴嫩派系 | 权重 = 实力[派系] |
| {行业} / {商品} / {议题} 等 | 事件条目中给出候选表 | 等权，或按条目写明的权重 |
| {方向} | 好/坏、上涨/下跌、加入/离开等 | 条目写明概率；多数事件的**方向概率随国家状态变化**（这是“结果缩放”的一部分，不是“发生缩放”） |

**记忆规则**：
- 同一事件的同一槽位组合，24个月内不重复；候选全部用完时才允许重复。
- 每条事件有一个**任期内计数** 记忆计数[R-xx]，用于“重复变化”；换届时清零，但记忆旗标（如“连续干旱”）保留到条件解除。

### 0.4 危机期间的暂停规则
- **战争状态**（任一战线处于交战）期间，以及停火后30天内：只保留安全类和灾害类随机事件（灾害不因战争停止）。
- **重大锚点事件弹出后14天内**：只保留安全类和灾害类随机事件。
- **玩家处于“选前60天”**：不暂停，但政坛与人事类的概率 ×1.5（建议值）。
- 安全类事件在危机期间如果与正在进行的战争重叠（例如战时的边境交火），改由战争系统结算，不单独弹窗；例外是前提写明“只在战争状态期间”的事件（如 R-59），照常弹窗。

### 0.5 通用写法约定
- **规模系数 k**：每条事件的“规模”一栏给出 k 的计算公式，效果中写“×k”的项乘以 k。除非另有说明，k 限制在 0.5–2 之间。
- **承诺的类别写法**：随机事件跨越所有剧本，不能写死某个承诺的名字。写作 承诺进度[经济类]、承诺进度[安全类]、承诺进度[社会类]、承诺进度[和平类]、承诺进度[宗教类]、承诺进度[移民类]，由引擎作用到当前剧本中带对应标签的承诺上；没有对应承诺时忽略。
- **立场轴的写法**：统一使用 立场偏离[安全]、立场偏离[经济]、立场偏离[宗教]、立场偏离[领土]、立场偏离[外交] 五条轴。正值表示向“离开本党走廊”的方向偏移，由引擎按当前政党的走廊判断方向：例如“强制复工令”对工党是偏离，对自由党是贴近。条目中写“立场偏离[经济] ±3（按走廊）”就是这个意思。各时代文件的轴统一之前（README 第2.8节），以本约定为准。
- **【小】**：标在标题后，表示所有选项都是小力度，可以由顾问自动处理。
- **后续抉择**：部分被动事件之后紧接一个抉择，写作 R-xxa，与母事件同时结算，不占月度名额。

## 一、灾害与事故

### R-01 旱年
- **类别**：灾害与事故
- **选项形式**：被动（附后续抉择 R-01a）
- **时代**：1948–2006
- **前提**：无
- **基础概率**：每月 8%（只在3–5月雨季结束时掷骰，等效每年约22%）
- **冷却**：12个月
- **上限**：无
- **随机槽位**：{区}（受灾最重的区，从加利利、内盖夫、戈兰高地、约旦河西岸、加沙中按农业人口加权抽取）；{水源}（太巴列湖 / 沿海含水层 / 山地含水层）
- **背景**：雨季结束了，全国降雨量只有常年的六成。{水源}的水位跌破红线，{区}的果园开始枯萎，莫沙夫的农民在讨论要不要提前宰杀牲畜。
- **规模**：k = 1.5 − 发展水平[{区}]/100；若 旗标：国家输水工程完工，k × 0.7；若 旗标：海水淡化计划，k × 0.5；若记忆旗标“连续干旱”存在，k + 0.3
- **被动效果**：经济增长 −0.5×k；财政 −1%×k（抗旱补贴）；发展水平[{区}] −2×k；选民集团支持[基布兹与莫沙夫] −3×k；若 {区} 为约旦河西岸或加沙：巴勒斯坦生活水平 −3×k，巴勒斯坦民间敌意 +2（水源分配争议）
  - **R-01a「水的配额」**（立即）：
    - **A「砍农业配额，保城市用水」**：选民集团支持[基布兹与莫沙夫] −4；盟党满意度[农业背景的盟党] −4；经济增长 −0.3；城市不受影响
    - **B「保农业，城市限时供水」**：选民集团支持[中产自由派] −3；选民集团支持[米兹拉希] −2（发展城镇断水最多）；立场偏离[经济] ±2（按走廊）
    - **C「动用外汇进口粮食，开采深层水」**：外汇 −2%×k；水源长期受损（修正器「超采」（36个月：下次 R-01 的 k +0.3））；没有人当场不满，但财政部长 人物关系 −5
- **重复变化**：第2次（三年内）：设置记忆旗标“连续干旱”，媒体开始问“国家水政策是什么”，R-01a 增加选项 **D「成立国家水务委员会，统一水价」**（政治资本 −15；工会实力 −2；选民集团支持[基布兹与莫沙夫] −5；修正器「统一水价」（永久：此后 R-01 的 k × 0.8））。第3次：基布兹运动公开批评政府，党内地位 −3。
- **时代变体**：
  - 1948–1955：过渡营地断水，移民吸收容量 −2×k；没有国家输水工程，k 不打折。
  - 1964年以后：国家输水工程把太巴列湖的水引到南方，{水源}为太巴列湖时，叙利亚的“引水改道”问题浮出水面，政权敌意[叙利亚] +2。
  - 1967年以后：山地含水层的分配成为占领区争议，巴勒斯坦相关效果生效。
  - 1994年以后：若与约旦签有和约，旱年时约旦要求按和约供水，R-01a 增加选项「照约供水」（关系改善：政权敌意[约旦] −3；选民集团支持[基布兹与莫沙夫] −3）。

### R-02 热浪与山火
- **类别**：灾害与事故
- **选项形式**：抉择
- **时代**：1948–2006
- **前提**：无
- **基础概率**：每月 3%（只在5–10月掷骰）
- **冷却**：6个月
- **上限**：无
- **随机槽位**：{区}（加利利、海法（卡尔迈勒山）、耶路撒冷（山区林带）、戈兰高地，按人口 × 林地系数加权）；{原因}（电线短路 70% / 疑似纵火 30%）
- **背景**：一连五天的东风（沙拉夫）把气温推到四十度以上。{区}的松林烧了起来，两个村子正在撤离，火光在海岸上都看得见。警方初步说法是：{原因}。
- **规模**：k = 1 + (100 − 发展水平[{区}])/200；1970年前消防能力弱，k + 0.3
- **选项**：
  - **A「请求外国派消防飞机」**：本次损失 × 0.5；党内地位 −2（“一个国家连火都扑不灭”）；若出手的是与以色列冷淡或敌对的国家：政权敌意[该国] −3，国际合法性 +1
  - **B「出动军队扑火」**：本次损失 × 0.7；战备 −3（1个月内）；财政 −0.5%
  - **C「宣布纵火是恐怖行为」**（仅 {原因} 为疑似纵火时可选）：本次损失不变；公众安全感 −3；选民集团支持[宗教犹太复国主义者] +2；国家认同度[阿拉伯人] −4；民主法治指数 −2；若事后查明是意外（50%）：政治资本 −10
  - 本次损失：发展水平[{区}] −2×k；财政 −0.5%×k；若 {区} 为加利利或海法，选民倾向[{区}] 对执政党 −1
- **重复变化**：第2次：犹太民族基金的植树捐款运动启动，关系[海外犹太社群] +2。第3次：媒体追问消防预算，增加选项 **D「设立国家消防局」**（财政 −1%；此后 R-02 的 k × 0.7）。
- **时代变体**：1950年代的山火多发生在新种的人工林里，选项A不可用（没有可以求助的邻国）；1967年以后 {区} 可以抽到戈兰高地，火势可能波及雷区（k + 0.2）；1990年代以后选项A可以向土耳其、希腊、塞浦路斯求援。

### R-03 冬季洪水
- **类别**：灾害与事故
- **选项形式**：被动
- **时代**：1948–2006
- **前提**：无
- **基础概率**：每月 2.5%（只在11–2月掷骰）
- **冷却**：12个月
- **上限**：无
- **随机槽位**：{区}（内盖夫、特拉维夫（阿亚隆河）、海法、加沙，按人口加权，内盖夫额外 ×1.5）；{地点}（未被承认的贝都因村庄 / 阿亚隆公路 / 下城的老街区 / 难民营）
- **背景**：一场冬季风暴两天内倒下了半年的雨量。{区}的旱谷突然变成河流，{地点}被水淹没。
- **规模**：k = 1.5 − 发展水平[{区}]/100；{地点} 为未被承认的贝都因村庄或难民营时 k × 1.5
- **被动效果**：发展水平[{区}] −2×k；财政 −0.5%×k；按 {地点}：
  - 贝都因村庄：土地怨气[贝都因人] +3（被拆过的村子连排水沟都不许修）
  - 阿亚隆公路：经济增长 −0.2；选民集团支持[中产自由派] −2
  - 老街区：疏离度[米兹拉希] +2
  - 难民营（加沙）：巴勒斯坦生活水平 −3×k；巴勒斯坦民间敌意 +1；国际组织呼吁援助，国际合法性 −1
- **重复变化**：第2次淹同一个地点时，背景改为“又一次”，相关群体效果翻倍，并解锁区级决策「修建排水工程」（花费 财政 −1%，此后该地点不再被抽中）。
- **时代变体**：1948–1955年，过渡营地的帐篷被冲垮（移民吸收容量 −3×k，见 E-G01-06 的联动）；1967年后可以抽到加沙；1990年代后特拉维夫的阿亚隆公路成为媒体焦点。

### R-04 死海断层地震
- **类别**：灾害与事故
- **选项形式**：被动（强震时附后续抉择 R-04a）
- **时代**：1948–2006
- **前提**：无
- **基础概率**：每月 0.3%
- **冷却**：24个月
- **上限**：强震每局1次
- **随机槽位**：{区}（沿裂谷带加权：加利利（太巴列、采法特）、耶路撒冷、内盖夫（死海、埃拉特）、约旦河西岸（杰里科））；{震级}（有感地震 85% / 强震 15%）
- **背景**：凌晨，大地晃了十几秒。震中在{区}附近的死海断层上。老人们想起了1927年的大地震。
- **规模**：k = (120 − 发展水平[{区}])/60（老城区、旧石屋越多，损失越大）；若 旗标：建筑抗震规范，k × 0.6
- **被动效果**：
  - 有感地震：公众安全感 −1；媒体讨论抗震加固（解锁决议「建筑抗震规范」：财政 −1%，旗标：建筑抗震规范）。
  - 强震（大力度）：发展水平[{区}] −12×k；财政 −4%×k；经济增长 −2×k；公众安全感 −6；关系[海外犹太社群] +4（紧急捐款）；国际合法性 +3（同情）；若 {区} 为耶路撒冷：30%概率老城圣地受损（旗标：圣地受损，宗教各方立即提出修复主导权）
  - **R-04a「重建的顺序」**（仅强震）：
    - **A「先救犹太社区与发展城镇」**：选民集团支持[米兹拉希] +3；国家认同度[阿拉伯人] −6；国际合法性 −3
    - **B「按受灾程度分配，不分社区」**：党内地位 −3；国家认同度[阿拉伯人] +3；民主法治指数 +1；政治资本 −10
    - **C「接受外国（包括阿拉伯国家）救援队进入」**：本次损失 × 0.8；国际合法性 +3；若约旦或埃及派队：政权敌意[该国] −5；盟党满意度[宗教党] −3（外国人员进入圣地）；立场偏离[安全] ±2（按走廊）
- **重复变化**：有感地震第3次时，背景改为“专家警告大震的周期已到”，抗震决议的政治资本成本减半。
- **时代变体**：1950年代石屋和临时棚屋居多，k + 0.3；1967年后可以波及东耶路撒冷圣地，圣地受损时约旦与伊斯兰宗教基金会提出修复要求；1994年后约以和约框架下的联合救灾可以触发 政权敌意[约旦] −8。

### R-05 公交车事故
- **类别**：灾害与事故
- **选项形式**：抉择
- **时代**：1948–2006
- **前提**：无
- **基础概率**：每月 3%
- **冷却**：6个月
- **上限**：无
- **随机槽位**：{区}（按人口加权）；{乘客}（学生郊游 / 朝圣者 / 士兵回营 / 工人通勤 / 游客）；{公司}（埃格德合作社 / 丹合作社 / 地方小公司）
- **背景**：一辆载着{乘客}的{公司}客车在{区}的山路上冲出护栏，滚落山谷。车上的人大部分没能救出来。

- **时代变体**：1957–1967年 {来源} 多为叙利亚与约旦方向的游击小队；1967–1970年约旦河谷的巴解渗透；1970年代后黎巴嫩边境成为主要方向；1985–2000年改为南黎巴嫩安全区的伏击（见 E-G04-18 的分工：本事件只处理越过边境的个案）；2000年后加沙边境的地道与越境袭击。
