## 0. 本文件使用的剧本设定（本-古里安 1948）

> [!IMPORTANT]
> 以下是本文件编写时采用的剧本假设。若与日后的剧本文件冲突，以剧本文件为准，并统一替换本文件中的名称。

**承诺（继承的使命）**

| 名称 | 来源 | 说明 |
|---|---|---|
| 承诺进度[赢得战争] | 建国即开战 | 国家生存、取得可防守的停战线 |
| 承诺进度[聚集流散者] | 犹太复国主义核心纲领、《独立宣言》 | 不设限的移民，并让新移民真正安顿下来 |
| 承诺进度[一支军队] | 本-古里安的个人纲领 | 解散党派武装与平行指挥体系 |
| 承诺进度[制定宪法] | 《独立宣言》规定由制宪议会制定宪法 | 本-古里安本人并不热心，这项承诺天然与集权度冲突 |

**立场走廊（马帕伊，1948–1955）**：正值表示偏出走廊，不分方向。
- 立场偏离[安全]：走廊为"积极防御、文官控制军队"。过度克制或过度冒险都会偏离。
- 立场偏离[经济]：走廊为"总工会主导的混合经济、国家计划与紧缩"。
- 立场偏离[宗教]：走廊为"维持现状协议，与宗教党合作但不让步于核心世俗领域"。
- 立场偏离[外交]：走廊为1950年前"不结盟"，1950年后"亲西方但不加入阵营"。

**愿景**
- 本-古里安：愿景进度「国家主义（Mamlachtiyut）」——以国家机构取代党派与运动的职能（军队、教育、劳工交换所），开发内盖夫，熔炉式整合移民。
- 夏里特（若本-古里安退隐后进入继承人模式）：愿景进度「以外交换安全」——边境克制、与西方结盟、寻找与阿拉伯国家的秘密渠道。1954–1955年的事件中，愿景进度后面注明适用人物。

**主要AI人物**：夏里特（外长）、卡普兰（财长，1952年去世）、埃什科尔（财长，1952年起）、多夫·约瑟夫（配给与供应部长）、拉冯、达扬、阿隆、雅丁、佩雷斯、贝京（赫鲁特）、莫舍·夏皮拉（工人米兹拉希）、迈蒙拉比（米兹拉希）、伊扎克·迈尔·莱文（以色列正教党）、梅厄·亚阿里与塔本金（马帕姆）。

**触发条件与效果中用到的世界状态**（属于共享状态或区级人口构成，不是新的矛盾参数）：阿拉伯难民人数、过渡营地人口、移民月流入、耶路撒冷通道宽度、黑市规模（由修正器「紧缩配给」持续时间与通胀派生）、各区人口构成。

**集权度在本时代的含义**：本-古里安时期的集权并不表现为取消选举，而是表现为"国家对党派、法院、议会和媒体的压倒性主导"。紧急条例、推迟宪法、绕开内阁、利用安全机构打击政治对手，都会推高集权度。集权度越高，行动越快、政治资本越便宜，但民主法治指数、盟党满意度和人物关系会持续受损，并解锁后续的"继承危机"事件。

## 1. 1948年

### E-1948-01 建国与入侵
- **类型**：锚点
- **选项形式**：被动
- **触发**：
  - **窗口**：剧本开局当日（1948-05-14）
  - **前置**：适用剧本：本-古里安 1948。规范例外：开局事件
  - **条件**：无（规范例外：开局事件）
  - **概率**：剧本开局时 100%
  - **失效**：无
  - **未触发**：无
- **背景**：1948年5月14日下午，本-古里安在特拉维夫博物馆宣读《独立宣言》，英国委任统治于午夜结束。次日，埃及、外约旦、叙利亚、伊拉克的军队和黎巴嫩部队进入原委任统治地区，内战阶段（1947-11起）转入国家间战争。美国在数分钟后给予事实承认，苏联在三天后给予法律承认。
- **被动效果**：修正器「独立战争」（持续到全部停战协定签订：战备每月 −2 的消耗，财政每月 −1.5%，公众安全感 −15，经济增长 −3个百分点）；国际合法性 +10；关系[苏联] +10；美国政府关系 +5；关系[海外犹太社群] +15；政权敌意[埃及/约旦/叙利亚/伊拉克/黎巴嫩] 设为 90；修正器「多支武装并存」（哈加纳、伊尔贡、莱希、帕尔马赫指挥部并存：战备上限 −15，承诺进度[一支军队] 无法超过 30，直到相关事件结算）；旗标：战争进行中
- **多视角**：
  - 伊休夫犹太人：大屠杀刚过去三年，人们相信这是一场决定民族存亡的战争；约1%的犹太人口将在战争中死去。
  - 巴勒斯坦阿拉伯人：内战阶段已有数十万人逃离或被驱逐，新国家的诞生在他们的记忆中是"大灾难"（纳克巴）的开端。
  - 阿拉伯国家政府：出兵既出于泛阿拉伯的民意压力，也出于彼此的争夺，外约旦的阿卜杜拉与其余各国互不信任。
- **备注**：开局时已发生的事（代尔亚辛、海法与雅法的人口外逃）以初始数值体现：土地怨气[阿拉伯人] 初始 40，巴勒斯坦民间敌意 初始 75。

### E-1948-02 阿尔塔莱纳号
- **类型**：锚点
- **选项形式**：抉择
- **触发**：
  - **窗口**：最早 1948-06-11，最晚 1948-07-08（第一次停火期间）
  - **前置**：旗标：战争进行中；修正器「多支武装并存」存在；旗标：第一次停火生效；人物[贝京] 在世且领导伊尔贡
  - **条件**：承诺进度[一支军队] < 60，且 战备 < 70（伊尔贡与政府都急需武器）
  - **概率**：每月 70%；人物关系[贝京] 每低10点 +5%；关系[法国] ≥ 40 时 +10%（武器船来源）
  - **失效**：修正器「多支武装并存」中的伊尔贡部分已移除；或 旗标：贝京入狱
  - **未触发**：无（武器船未出现，伊尔贡在停火结束后逐步并入国防军，承诺进度[一支军队] +5）
- **背景**：5月26日以色列国防军成立，伊尔贡同意以营为单位并入，但在耶路撒冷保持独立。第一次停火期间（6月11日起），伊尔贡从法国购买的武器船"阿尔塔莱纳号"抵达卡法维特金海岸。贝京要求把两成武器分给耶路撒冷的伊尔贡部队和并入国防军的伊尔贡营，政府要求全部交出。
- **选项**：
  - **A「交出全部武器，否则开火」【史实】**：在卡法维特金和特拉维夫海滩交火，船只被炮击起火，16名伊尔贡成员和3名国防军士兵死亡；承诺进度[一支军队] +20；移除修正器「多支武装并存」中的伊尔贡部分；战备 −3（武器沉入海中）；人物关系[贝京] −40；集权度 +5；民主法治指数 −2；党内地位 +5；政治资本 −10
    - 后续：若贝京的人物特质为"拒绝内战"（史实），他下令不还击；旗标：阿尔塔莱纳之痛（赫鲁特此后数十年的动员叙事，选民集团支持[米兹拉希] 向赫鲁特的转移在1970年代额外 +5%）
  - **B「谈判分配：部分武器归入耶路撒冷部队」**：战备 +5；承诺进度[一支军队] −10；人物关系[贝京] +15；党内地位 −8（马帕伊和帕尔马赫视为向"分裂分子"让步）；人物关系[加利利] −15；修正器「伊尔贡耶路撒冷独立部队」（直到耶路撒冷停火：每月有5%概率违反停火，国际合法性 −3）
  - **C「借机取缔伊尔贡，逮捕贝京」**：承诺进度[一支军队] +25；集权度 +15；民主法治指数 −10；人物关系[贝京] −80；国际合法性 −3；选民集团支持[米兹拉希] −5；旗标：贝京入狱
    - 后续：修正器「右翼地下复燃」（36个月：每季度有10%概率发生政治暴力事件，公众安全感 −3）；首届选举中赫鲁特以"殉道者党"参选，席位 +4
- **多视角**：
  - 政府：停火期间运进武器本身就违反停火协定，如果一支私人武装可以自己进口武器，国家就不存在。
  - 伊尔贡成员：他们刚把武器和兵员交给新军队，却在海滩上被犹太人的炮火击中；许多人认为这是马帕伊对政敌的清算。
  - 帕尔马赫士兵：很多人亲手执行了开火命令，这件事在他们之间也留下了长久的沉默。
- **备注**：拉宾当时在特拉维夫海滩的帕尔马赫指挥部。

### E-1948-03 难民能否回来
- **类型**：锚点
- **选项形式**：抉择
- **触发**：
  - **窗口**：最早 1948-06，最晚 1948-09
  - **前置**：旗标：战争进行中
  - **条件**：阿拉伯难民人数 > 30万，且 公众安全感 < 60
  - **概率**：每月 50%；阿拉伯难民人数 每多10万 +15%；国际合法性 > 60 时 +10%（联合国调解人施压）
  - **失效**：旗标：难民已大规模回归（架空）；或 阿拉伯难民人数 < 5万
  - **未触发**：由AI内阁自动按「战时不许回归」处理（等同选项A，但 政治资本 无消耗也无收益，人物关系[夏里特] −3）
- **背景**：到1948年6月，约30万巴勒斯坦阿拉伯人已离开家园。6月16日内阁讨论后形成共识：战争期间不允许难民回来。在此前后，一些地方开始拆毁空置村庄，耕地被交给邻近的基布兹耕种。
- **选项**：
  - **A「战时不许回归，最终处理留待和会」【史实】**：公众安全感 +5；巴勒斯坦民间敌意 +8；国际合法性 −5；承诺进度[聚集流散者] +5（空置房屋用于安置移民）；旗标：拒绝回归
    - 后续：修正器「空置村庄」（土地怨气[阿拉伯人] 每年 +1，持续到难民问题解决）；→ E-1949-07
  - **B「允许有限回归：亲属团聚与未参战村庄」**：国际合法性 +8；美国政府关系 +5；公众安全感 −5；党内地位 −5；立场偏离[安全] +5；人物关系[雅丁] −10；巴勒斯坦民间敌意 −3；区级人口构成：加利利与海法阿拉伯人口 +5万（三难三角中犹太人口占比下降）
  - **C「宣布永久禁止回归，系统性拆除空村」**：公众安全感 +6；承诺进度[聚集流散者] +8；国际合法性 −12；巴勒斯坦民间敌意 +15；土地怨气[阿拉伯人] +10；民主法治指数 −3；关系[英国] −5；集权度 +3
    - 后续：修正器「回归之梦」（永久：巴勒斯坦民间敌意 下限 +10）
- **多视角**：
  - 内阁多数：回来的人在战时就是第五纵队，而且和会迟早会召开。
  - 难民：大多数人以为几周后就能回家，带走的只有钥匙。
  - 马帕姆的基布兹成员：他们一边接收邻近村庄的田地，一边在党内会议上为"阿拉伯劳动者的权利"争吵。

### E-1948-03a 达尼行动：对占领城镇居民的指令
- **类型**：锚点
- **选项形式**：抉择
- **触发**：
  - **窗口**：最早 1948-06-15，最晚 1948-07-10（第一次停火结束前夕）
  - **前置**：旗标：战争进行中；旗标：第一次停火生效；中部攻势（「达尼行动」）已列入作战计划
  - **条件**：战备 ≥ 40，且 安全[特拉维夫] < 70 或 安全[耶路撒冷] < 60
  - **概率**：每月 80%
  - **失效**：中部攻势取消；或 吕大与拉姆勒已以其他方式结算
  - **未触发**：由AI国防体系按选项A处理
- **背景**：作战计划要求夺取吕大和拉姆勒。两城连同涌入的难民共约5万至7万人，紧邻机场与通往耶路撒冷的公路，阿拉伯军团就在附近，而国防军兵力吃紧。指挥官们问：占领之后，居民怎么办？史实上，政府没有就城镇居民下达书面政策，处置权实际上留给了战地指挥官。
- **选项**（事前决策：玩家只看到顾问给出的风险评估，不知道结果）：
  - **A「不下书面指令，交由战地指挥官依情势处理」【史实】**：政治资本 +5；人物关系[阿隆] +5；战备 +2；旗标：平民政策空白
    - 风险：E-1948-04（吕大与拉姆勒）发生概率 ×1.0（顾问评估："相当可能出现大规模人口外移"）
  - **B「书面命令：居民留在原地，由军政府管理，禁止驱逐与抢掠」**：政治资本 −10；战备 −3（需要留兵看守）；人物关系[阿隆] −8；盟党满意度[马帕姆] +5；民主法治指数 +3
    - 风险：E-1948-04 发生概率 ×0.3（顾问评估："可能性较低，但战场情况难以控制"）；未发生时 → 架空事件「留下的吕大」
  - **C「授权清除交通线沿线的敌对人口」**：战备 +4；公众安全感 +3；民主法治指数 −5；盟党满意度[马帕姆] −8；修正器「驱逐指令」（隐藏，永久：文件档案解密或外泄时 国际合法性 −10，关系[海外犹太社群] −5）
    - 风险：E-1948-04 发生概率 ×1.5，且其被动效果中的 巴勒斯坦民间敌意、阿拉伯难民人数、土地怨气[阿拉伯人] ×1.5（顾问评估："几乎肯定"）
- **多视角**：
  - 前线指挥官：手头的兵力不够同时守住两座敌对城市和抵挡阿拉伯军团。
  - 马帕姆部长：一个刚刚宣布"全体居民完全平等"的国家，不能把驱逐当作作战手段。
- **备注**：事前决策点（README 第4节第4条）。C选项的短期军事收益小于其长期代价。

### E-1948-04 吕大与拉姆勒
- **类型**：锚点
- **选项形式**：被动
- **触发**：
  - **窗口**：最早 1948-07-08，最晚 1948-08-31（第一次停火结束后的攻势期）
  - **前置**：E-1948-03a 已结算（事前决策点）；旗标：战争进行中；第一次停火已结束；玩家或AI国防体系已批准中部攻势（「达尼行动」）
  - **条件**：战备 ≥ 40，且 安全[特拉维夫] < 70 或 安全[耶路撒冷] < 60（通道受威胁），且 民主法治指数 < 70
  - **概率**：攻势发起当月 60% × E-1948-03a 乘数（A ×1.0，B ×0.3，C ×1.5）；修正器「军纪」存在时再 ×0.6；人物关系[阿隆] ≥ 20 时 +10%；民主法治指数 每高10点 −10%
  - **失效**：吕大与拉姆勒已以其他方式（谈判投降且居民留下）结算；或 旗标：报复只打军事目标 之类的平民保护命令在攻势前已生效
  - **未触发**：两城被占领但居民大部分留下 → 架空事件「留下的吕大」（阿拉伯公民人口增加，三角地带与中部的军事管制需求上升）
- **背景**：第一次停火于7月8日结束。在打通特拉维夫至耶路撒冷通道的"达尼行动"中，国防军于7月11–12日占领吕大和拉姆勒。吕大城内一次交火后，部队向人群和一座清真寺开火，死亡人数估计从约百人到二百五十人以上不等。7月12–13日，两城约5万至7万居民被驱逐，在盛夏步行走向阿拉伯军团防线，途中有人死于酷热和脱水。
- **被动效果**：战备 +5；公众安全感 +5；承诺进度[赢得战争] +8；巴勒斯坦民间敌意 +12；政权敌意[约旦] +5；民间敌意[约旦] +10（难民涌入外约旦）；土地怨气[阿拉伯人] +5；阿拉伯难民人数 +6万；旗标：吕大驱逐；→ E-1948-05
- **多视角**：
  - 国防军指挥官：两城位于机场和公路要冲，阿拉伯军团近在咫尺，留下敌对人口会牵制本已不足的兵力。
  - 吕大居民：被驱逐者的长队中有日后的人阵领导人乔治·哈巴什，这段步行成为巴勒斯坦民族记忆的核心场景之一。
  - 内阁中的马帕姆部长：齐斯林等人质问"谁下的命令"，这个问题此后在内阁和史学界争论了数十年。
- **备注**：书面驱逐令由行动司令部发出。本-古里安是否口头授意，源于拉宾回忆录中曾被审查删去的段落，史学界有争议，事件文本不作定论。

### E-1948-05 吕大与拉姆勒：事后处置

- **选项形式**：抉择
- **触发**：

- **选项**：

  - **B「空运，同时动用财政为伊拉克中产专业人士优先提供城市住房和职位」**：承诺进度[聚集流散者] +15；移民吸收容量 −15；财政 −4%；疏离度[米兹拉希] −5；选民集团支持[米兹拉希] +5；选民集团支持[劳工派阿什肯纳兹] −3（住房排队被插队）；经济增长 +0.5个百分点（专业人才）

- **多视角**：
  - 伊拉克犹太人：一个两千五百年历史的社群在一年内几乎全部离开，很多人到达后才发现自己要住帐篷。
  - 以色列政府：伊拉克政局随时可能变卦，能接出来的人必须尽快接出来。
  - 伊拉克民族主义者：犹太人被视为与犹太复国主义者有关联，这种猜疑本身加剧了排斥。

### E-1950-04 哈拉里决议：暂缓制宪
- **类型**：锚点
- **选项形式**：抉择
- **触发**：
  - **窗口**：制宪议会就职后 6–24 个月；最早 1949-08，最晚 1951-06

- **背景**：《独立宣言》要求制宪议会制定宪法。宗教党担心宪法会确立世俗国家，本-古里安担心宪法会束缚政府和议会，也不愿与宗教党决裂。6月13日议会通过进步党议员伊兹哈尔·哈拉里提出的折中决议：宪法将分章以"基本法"的形式逐步制定，不设期限。

  - **C「宣布在战争状态下暂停制宪，以紧急条例治理」**：集权度 +12；承诺进度[制定宪法] −20；民主法治指数 −8；盟党满意度[进步党] −15；人物关系[贝京] −10；选民集团支持[中产自由派] −8；政治资本 +10

    - 后续：移除未来的"未解的伤口"修正器；若调查发现非法领养证据（概率由沙盒设定，默认低），触发丑闻事件：党内地位 −10，但 历史怨气[米兹拉希] 进一步 −5
  - **C「否认问题存在，指责投诉者散布谣言」**：政治资本 +5；历史怨气[米兹拉希] +12；疏离度[米兹拉希] +6；民主法治指数 −3；旗标：也门儿童之谜
- **多视角**：
  - 也门家庭：他们不懂希伯来语，也不懂医院的手续，孩子被抱走后就再也没有见过。
  - 医护人员：营地中麻疹、痢疾肆虐，婴儿死亡率极高，医护人员严重不足。
  - 后世的调查者：大多数证据指向死亡和混乱的记录，但混乱本身也足以构成国家的失职。
- **备注**：这是仍有现实争议的议题，文本保持各调查结论的原貌，不预设结论。
