## 1. 事件条目模板

```markdown
### E-1950-03 过渡营地的冬天
- **类型**：锚点 | 结构 | 人物 | 风味
- **选项形式**：抉择（2–3个选项）| 被动（无选项）
- **触发**：（结构化子项，见第5节）
  - **窗口**：1950-11 至 1951-03
  - **前置**：动态区或旗标等
  - **条件**：移民吸收容量 < 30，且 过渡营地人口 > 10万
  - **概率**：每月 40%
  - **失效**：……
  - **未触发**：无
- **背景**：1–3句史实。
- **选项**：
  - **A「选项标题」**：效果1；效果2；……
    - 后续：（可选）N个月后触发的事件或修正器
  - **B「……」**：……
  - **C「……」**：……
- **被动效果**：（被动事件填写这一项，代替"选项"）
- **多视角**：（仅重大事件）2–3个群体的一句话视角
- **备注**：（可选）设计说明；涉及在世人物时标注【在世人物】
```

### 2.7 编号约定
- 有日期的事件：E-年份-序号，同月多个事件可加 a/b/c，例如 E-1982-09a。
- 时代通用事件：E-G01-xx 至 E-G05-xx，对应五个时代文件。

### 2.8 统一的立场轴与承诺标签
- **五条全局立场轴**：立场偏离[领土]、立场偏离[安全]、立场偏离[经济]、立场偏离[宗教]、立场偏离[外交]。每个政党在每条轴上定义自己的可接受区间；事件里写作“±N（按走廊）”，偏离方向由当前执政党的走廊决定。
- **承诺类别标签**（供随机事件等跨剧本内容使用）：承诺进度[经济类/安全类/社会类/和平类/宗教类/移民类]，结算到当前剧本中同类别的具体承诺上。
- 各时代文件第0节中自定的轴（如“安全/经济/宗教/外交”“领土/经济/安全”），在进入原型时映射到上述五条轴。

## 4. 编写原则

1. **每个选项都要得罪某一方**，不设"免费选项"；尽量触及承诺、立场走廊、愿景三层中的至少一层。
2. **被动事件**约占25–30%：战争爆发、自然死亡、外国政变、经济冲击等玩家无法选择的事。被动事件之后常常接一个抉择事件。
3. **极端选项永远不划算**（见设计文档第17节）：屠杀、驱逐、集体惩罚之类的选项，长期代价必须超过短期收益。
4. **暴行类事件有两个抉择点**：事前的政策决策点只呈现风险概率，玩家不知道结果（例如是否组建101部队、是否允许长枪党进入难民营）；暴行本身是被动事件；之后再由总理做事后处置，例如卡夫尔卡西姆屠杀之后是审判还是掩盖。
5. **多视角**：重大事件写出不同群体的视角，不站队。
6. 选项尽量包括历史上真实的选择，并标注【史实】。
7. **历史引力与外部世界**：锚点事件的概率以"不干预时约70–80%重演"为校准目标；外国政局默认沿史实轨道推进并带随机扰动（见设计文档第15.4–15.5节）。

## 5. 触发条件规范（固定事件）

> [!IMPORTANT]
> 所有固定事件（编号 E-）都**必须**有结构化的触发条件。**不允许只按日期触发**，也不允许“或历史日期”“历史模式按日期”这类兜底写法。沙盒里历史偏离后，条件不满足的事件就不会发生，或者改为触发替代事件。

### 5.1 触发字段
`- **触发**：` 一行改写为以下子项：

```markdown
- **触发**：
  - **窗口**：最早 1977-09，最晚 1978-03（锚点事件以史实日期为中心；后续事件写"前置事件结算后 N–M 个月"）
  - **前置**：旗标、已发生的事件、存在的动态区、在世且在任的人物（例如 人物[萨达特] 在任）
  - **条件**：数值阈值，用"且 / 或"连接，至少一项数值条件
  - **概率**：条件满足期间的每月触发概率，例如 每月 25%；可以附修正项（例如 政权敌意[埃及] 每低10点 +10%）
  - **失效**：事件永远不再可能发生的情况（例如 人物[萨达特] 死亡，或 旗标：埃以和约已签署）
  - **未触发**：窗口关闭仍未触发时的处理：无 / 触发替代事件 → E-xxxx / 由AI自行推进
```

### 5.2 各类事件的写法要点
| 类型 | 窗口 | 条件的重点 |
|---|---|---|
| 锚点 | 史实日期前后数月到数年 | 历史前提（人物、旗标）+ 数值阈值 |
| 结构 | 时代范围 | 数值阈值为主，另写**冷却**（多久内不再触发） |
| 人物 | 人物在世、在任期间 | 人物属性（野心、健康、关系）|
| 风味 | 时代范围 | 简单条件即可，概率偏低 |
| 后续 | 前置事件结算后 N–M 个月 | 前置选项 + 至少一项会让后续"变大或变小"的数值 |
| 开局 | 剧本开局 | 写明适用的剧本；非该剧本开局时，改写为一般条件 |

## 6. 随机事件（编号 R-）

> 见 [06_random_events.md](06_random_events.md)。

### 6.1 定义
- **会不会发生是纯随机的**：只受时代和最基本的前提限制（例如"存在加沙动态区"），不由玩家的政策决定。
- **后果由国家状态决定**：同一场旱灾，水利投资多的国家损失更小；同一场罢工，工会实力越强越难收场。这样随机事件也和玩家的决策有关。
- **可以反复发生**：有冷却时间；每次发生的地点、群体、人物、国家由随机槽位决定，文本随之变化。

### 6.2 随机事件模板
```markdown
### R-07 公交车事故
- **类别**：灾害与事故
- **选项形式**：抉择 | 被动
- **时代**：1948–2006（或某个年份范围）
- **前提**：（可选）最基本的存在性条件
- **基础概率**：每月 3%
- **冷却**：6个月
- **上限**：无 / 每届任期N次
- **随机槽位**：{区}、{群体}、{部长}、{国家} 等，在事件发生时抽取
- **背景**：带槽位的模板文本，例如"{区}的一辆公交车坠入山谷……"
- **规模**：后果随哪些状态缩放（例如 损失 × (1 − 发展水平[{区}]/200)）
- **选项**：
  - **A「……」**：效果
  - **B「……」**：效果
- **被动效果**：（被动事件填写）
- **重复变化**：同一任期内第2次、第3次发生时，文本和效果怎样变化（例如媒体开始追问"为什么又发生了"）
- **时代变体**：不同年代的文本或效果差异
```

### 6.3 频率预算
| 规则 | 数值（示意） |
|---|---|
| 平时随机事件的平均频率 | 每个游戏月约1条 |
| 每月上限 | 2条 |
| 危机期间（战争、重大锚点事件弹出后14天内） | 随机事件暂停，只保留安全类和灾害类 |
| 被动事件比例 | 约40% |
| 小事件 | 玩家可以设置为由顾问自动处理，顾问按玩家的立场走廊选择 |
