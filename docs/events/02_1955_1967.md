# 事件库 02：1955–1967（本-古里安复出至六日战争结束）

> [!NOTE]
> 覆盖 1955-11（本-古里安重任总理）至 1967-06-10（六日战争停火）。全部事件以**总理视角**编写，格式与数值名称遵循 [README.md](README.md)。数值均为示意，需原型校准。

## 0. 本时代的剧本语境

本文件横跨两位总理，事件按"谁在总理位置"读取同一套数值：

| 时段 | 总理（玩家） | 开局承诺（承诺进度[…]） | 个人愿景（愿景进度） |
|---|---|---|---|
| 1955-11 至 1963-06 | 本-古里安（1955复出开局，或1949剧本延续） | 承诺进度[边境安全]：止住越境渗透与袭击；承诺进度[打破军火孤立]：在捷克军火交易后找到稳定的武器来源 | 「国家主义」（Mamlachtiyut）：以国家机构取代党派与运动，开发内盖夫，建立安全上的自立（含核选项） |
| 1963-06 至 1967-06 | 埃什科尔（1963剧本） | 承诺进度[党内团结]：继承一个被拉冯事件撕裂的马帕伊；承诺进度[经济稳定]：给过热的经济降温；承诺进度[放宽军事管制]：逐步解除对阿拉伯公民的军事管制 | 「和解与常态化」：与修正派和解、与阿拉伯公民和解、与美国建立正式的军售关系 |

**马帕伊的立场走廊（立场偏离的四条轴）**：
- 立场偏离[安全]：走廊为"积极防御、有限报复"。过鸽（放弃报复）或过鹰（征服、吞并）都会增加偏离。
- 立场偏离[经济]：走廊为"国家主导、工会核心的混合经济"。
- 立场偏离[宗教]：走廊为"维持现状协议"。
- 立场偏离[外交]：走廊为"亲西方但不公开依附，保持行动自由"。

**集权度在本时代的主要来源**：军事管制、新闻审查（编辑委员会）、辛贝特的国内用途、绕过内阁的秘密决策（核计划、色佛尔）、借党务清洗对手。本-古里安时期的"国家主义"和集权路线在机制上高度重叠，玩家需要自己拿捏边界。

## 1. 锚点事件（按时间排序）

### E-1955-11a 捷克军火的阴影
- **类型**：锚点
- **选项形式**：被动
- **触发**：
  - **适用剧本**：1955年起始（本-古里安复出）的开局事件，开局当日结算；其他开局（含1949剧本延续）按下列一般条件判定
  - **窗口**：最早 1955-09，最晚 1956-06
  - **前置**：人物[纳赛尔] 在任（沿历史轨道）；旗标：西方拒售埃及武器（沿历史轨道）
  - **条件**：政权敌意[埃及] ≥ 45，且 美国政府关系 < 60（美国未把以色列纳入安全安排）
  - **概率**：每月 30%；政权敌意[埃及] 每高10点 +10%；旗标：加沙突袭（1955-02）存在 +20%
  - **失效**：旗标：西方对埃及军售 达成；或 人物[纳赛尔] 下台；或 旗标：埃以秘密和谈成功
  - **未触发**：无（埃及未获苏联武器，修正器「军力失衡」不生成）
- **背景**：1955年9月，纳赛尔宣布从捷克斯洛伐克（实为苏联）购入大批米格战机、坦克和火炮，数量远超以色列全部装备。11月本-古里安重任总理时，总参谋部估计军力平衡将在一年内彻底倒向埃及。
- **被动效果**：政权敌意[埃及] +5；战备相对值 −10（以修正器表示）；公众安全感 −8；威慑值 −5；修正器「军力失衡」（直到 承诺进度[打破军火孤立] ≥ 60：公众安全感 每月 −0.5，政治资本 月产出 −2）；关系[苏联] −5。
  - 后续：解锁 → E-1956-06b（法国军火渠道）；解锁 → E-1955-12（报复行动的诱惑）。
- **多视角**：
  - 以色列国防部：一扇正在关上的窗口，"要么现在，要么永不"。
  - 开罗：巴格达条约与西方禁运之后，终于有人愿意卖武器给我们。
  - 莫斯科：以最低的代价打开进入中东的大门。

### E-1955-12 基内雷特行动
- **类型**：锚点
- **选项形式**：抉择
- **触发**：
  - **窗口**：E-1955-11a 结算后 1–6 个月，最晚 1956-06
  - **前置**：E-1955-11a 已发生；人物[夏里特] 任外交部长且正在对美求购武器
  - **条件**：安全[加利利] < 50，且 政权敌意[叙利亚] ≥ 40，且 承诺进度[打破军火孤立] < 40
  - **概率**：每月 35%；安全[加利利] 每低10点 +10%；人物关系[达扬] ≥ 30 时 +10%
  - **失效**：夏里特离任外交部长；或 承诺进度[打破军火孤立] ≥ 60
  - **未触发**：无（湖区冲突转由 E-G02-01 处理）
- **背景**：叙利亚哨所多次向湖上的以色列警艇和渔船开火。国防部提出夜袭湖东岸的叙利亚阵地。此时外交部长夏里特正在华盛顿请求美国出售武器。
- **选项**：
  - **A「批准大规模夜袭」【史实】**：威慑值 +6；政权敌意[叙利亚] +6；民间敌意[叙利亚] +5；国际合法性 −6；美国政府关系 −8（夏里特的军购请求被搁置）；人物关系[夏里特] −20；人物关系[达扬] +10；承诺进度[边境安全] +5；承诺进度[打破军火孤立] −5。
    - 后续：联合国安理会谴责（国际合法性再 −3）；夏里特私下称"魔鬼本人也想不出更好的办法来破坏我的任务"，旗标：夏里特离心。
  - **B「推迟到夏里特返国之后」**：美国政府关系 +3（谈判继续，但美方最终仍大概率拒售）；人物关系[夏里特] +10；人物关系[达扬] −8；威慑值 −3；党内地位 −3（行动派抱怨总理变软）；立场偏离[安全] +3。
  - **C「只做有限炮击回应」**：威慑值 +2；国际合法性 −2；政权敌意[叙利亚] +2；人物关系[达扬] −4；人物关系[夏里特] +3；政治资本 −5。
- **备注**：这是一个"安全与外交"互相拆台的典型事件。玩家会发现美国的武器几乎不可能到手，这推动玩家转向法国。

### E-1956-05 德鲁兹人的义务兵役
- **类型**：锚点
- **选项形式**：抉择
- **触发**：
  - **窗口**：最早 1955-11，最晚 1957-06
  - **前置**：旗标：少数民族部队（德鲁兹志愿兵已在军中服役）
  - **条件**：国家认同度[德鲁兹人] ≥ 40，且 人物关系[德鲁兹宗教领袖] ≥ 0
  - **概率**：每月 15%；国家认同度[德鲁兹人] 每高10点 +5%
  - **失效**：国家认同度[德鲁兹人] < 25（谢赫撤回请求）
  - **未触发**：窗口顺延至 1960-12，概率减半；仍未触发则无
- **背景**：德鲁兹社群此前已有志愿者在军中服役（少数民族部队）。1956年，部分德鲁兹谢赫正式要求把义务兵役扩展到德鲁兹男子，政府同意，此后德鲁兹人被纳入征兵，而穆斯林与基督徒阿拉伯人仍不征召。
- **选项**：
  - **A「实行德鲁兹义务兵役，并单独登记为'德鲁兹'群体」【史实】**：国家认同度[德鲁兹人] +12；战备 +2；国家认同度[阿拉伯人] −4（被视为"分而治之"）；选民集团支持[阿拉伯公民] −2；旗标：德鲁兹血盟 = 是（解锁后续"血盟破裂"阈值事件）；集权度 +1。
    - 后续：修正器「兵役换平等的承诺」（永久：如果加利利的德鲁兹村庄 发展水平 长期低于犹太社区，国家认同度[德鲁兹人] 每年 −2，土地怨气[德鲁兹人] 每年 +2）。
  - **B「维持志愿服役」**：国家认同度[德鲁兹人] −3；德鲁兹谢赫 人物关系 −10；避免族群分化（国家认同度[阿拉伯人] 不变）；战备 −1。
  - **C「义务兵役，同时承诺德鲁兹村庄与犹太社区预算同等」**：国家认同度[德鲁兹人] +15；财政 −1%；发展水平[加利利] +3；政治资本 −10；国家认同度[阿拉伯人] −2。
- **多视角**：
  - 德鲁兹谢赫：我们的未来系于这个国家，兵役是我们换取尊重的方式。
  - 一位拿撒勒的穆斯林教师：他们在给"阿拉伯人"这个词切出不同的类别。
  - 国防部：一支可靠的少数民族部队，边境巡逻有了熟悉地形的人。

### E-1956-06a 夏里特的去留
- **类型**：人物
- **选项形式**：抉择
- **触发**：
  - **窗口**：E-1955-12 结算后 3–9 个月（且不早于 1956-03）
  - **前置**：人物[夏里特] 任外交部长；旗标：夏里特离心
  - **条件**：人物关系[夏里特] < 0，且（承诺进度[打破军火孤立] < 50 或 政权敌意[埃及] ≥ 60）
  - **概率**：每月 25%；人物关系[夏里特] 每低10点 +5%
  - **失效**：夏里特离任；或 人物关系[夏里特] ≥ 20
  - **未触发**：无（夏里特留任，E-1956-10a 中的内阁阻力不变）
- **背景**：本-古里安认为夏里特的外交节制已妨碍备战，于1956年6月迫使其辞去外交部长，由梅厄接任。夏里特此后在政治上被边缘化，但在马帕伊温和派中仍有影响力。
- **选项**：
  - **A「迫使夏里特辞职，梅厄接任外交部」【史实】**：人物关系[夏里特] −40；人物关系[梅厄] +15；党内地位 +3（本-古里安对党的控制增强）；集权度 +3；立场偏离[安全] +2；国际合法性 −3（西方外交圈失去了熟悉的温和面孔）；解锁：备战决策不再受外交部掣肘（E-1956-10a 色佛尔 中内阁阻力 −50%）。
    - 后续：旗标：温和派积怨（拉冯事件重燃时，温和派更倾向站在拉冯一边）。
  - **B「保留夏里特，但把军火外交交给国防部」**：人物关系[夏里特] −5；人物关系[佩雷斯] +10；外交出现"双轨"：关系[法国] 的增长速度 +25%，但每次秘密行动暴露风险 +10%；政治资本 −10。
  - **C「与夏里特和解，接受外交优先」**：人物关系[夏里特] +20；国际合法性 +4；美国政府关系 +3；人物关系[达扬] −10；人物关系[佩雷斯] −10；承诺进度[打破军火孤立] −5；立场偏离[安全] +3。

  - **C「同时向英国与美国试探，避免押注一国」**：承诺进度[打破军火孤立] +5；关系[法国] −3；美国政府关系 +2；政治资本 −5；修正器「军力失衡」持续期间额外 公众安全感 −2。

### E-1956-10d 战时的开火规则
- **类型**：锚点

- **触发**：
  - **窗口**：E-1956-10a 结算后 0–1 个月；自主路线下，玩家下令对埃及开战前 0–1 个月

  - **概率**：每月 6%；愿景为「国家主义」时 +4%
  - **冷却**：18个月
  - **失效**：加利利 犹太人口比例 ≥ 60%
  - **未触发**：无
- **背景**：政府长期推行"加利利犹太化"，在阿拉伯村庄的土地上建立犹太城镇，例如1957年的上拿撒勒，和1964年在征用了代尔阿萨德、比那、纳赫夫等村庄土地后建立的卡尔米埃勒。征地依据《土地征用法》和"缺席者财产"等法律。
- **选项**：
  - **A「依法征用阿拉伯村庄土地建立犹太新城」（接近【史实】）**：发展水平[加利利] +5；选民倾向[加利利] 马帕伊 +；土地怨气[阿拉伯人] +10；国家认同度[阿拉伯人] −5；若征用德鲁兹村庄土地，土地怨气[德鲁兹人] +6；民主法治指数 −2；愿景进度（本-古里安）+3。
  - **B「在国有土地和已有犹太定居点周边扩建，避开村庄土地」**：发展水平[加利利] +2；财政 −1%；土地怨气[阿拉伯人] +2；政治资本 −10；愿景进度 +1。
  - **C「同时为阿拉伯城镇批准规划与扩建用地」**：发展水平[加利利] +4；土地怨气[阿拉伯人] −3；国家认同度[阿拉伯人] +4；财政 −1.5%；党内地位 −4；立场偏离[安全] +2。
- **备注**：土地怨气是债务型参数，A选项的代价会在1976年"土地日"式的阈值事件中兑现。

### E-G02-06 "土地"运动与民主的边界
- **类型**：结构
- **选项形式**：抉择
- **触发**：
  - **窗口**：1959-01 至 1967-06
  - **前置**：旗标：阿拉伯民族主义组织出现
  - **条件**：国家认同度[阿拉伯人] < 35，且 政权敌意[埃及] ≥ 50
  - **概率**：每月 5%
  - **冷却**：24个月
  - **失效**：军事管制已废除，且 国家认同度[阿拉伯人] ≥ 50
  - **未触发**：无
- **背景**：阿拉伯民族主义团体"土地"运动（阿尔-阿尔德）支持纳赛尔式的泛阿拉伯主义，1964年被宣布为非法；1965年中央选举委员会以"否认国家存在"为由禁止其候选名单参选，最高法院维持了这一决定。
- **选项**：
  - **A「取缔组织并禁止参选」【史实】**：公众安全感 +2；民主法治指数 −5；国家认同度[阿拉伯人] −5；选民集团支持[阿拉伯公民] −4；集权度 +3；旗标：防御性民主先例。
  - **B「允许其活动与参选，加强监控」**：民主法治指数 +3；国家认同度[阿拉伯人] +3；公众安全感 −3；集权度 +1；党内地位 −3；人物关系[哈雷尔]/辛贝特首长 −8。
  - **C「允许参选，同时把马帕伊的阿拉伯附属名单改为真正的阿拉伯议员晋升通道」**：国家认同度[阿拉伯人] +5；选民集团支持[阿拉伯公民] +6；政治资本 −15；党内地位 −4。

### E-G02-09 总理的心脏
- **类型**：人物

  - **条件**：人物健康[总理] < 50，且处于高压状态（旗标：等待期、旗标：战争进行中，或 拉菲分裂 发生后6个月内）
