# 各对矛盾的参数设计（精简版）

> [!NOTE]
> 规则：**每对矛盾用1–2个参数，最多3个；涉及不同群体或势力时，每个对象1–3个参数。**
> 本文是主设计文档 [design_document.md](design_document.md) 第6节的展开。所有系数和阈值都是示意，需要通过原型校准。

---

## 0. 精简原则

为了把参数控制在规定数量内，先把四类东西分开，**只有第一类计入矛盾参数**：

| 类别 | 说明 | 例子 |
|---|---|---|
| **矛盾参数** | 矛盾本身的状态，随时间累积或变化 | 宗教现状指数、疏离度 |
| **政策杠杆** | 玩家设定的法令和滑块，是参数的**输入**，本身不是状态 | 军事管制强度、豁免覆盖率、定居点政策 |
| **共享状态** | 已在别处定义、多个矛盾共用 | 选民集团支持、盟党满意度、财政、区级人口构成 |
| **修正器与事件** | 阈值触发后产生的临时或永久效果 | 人才外流、住房危机、圣地冲突 |

**参数类型**：
- **轴**：−100 ↔ +100，两端各有代价
- **存量**：0–100，会累积或衰减
- **债务**：只增不减，除非玩家主动偿还，拖得越久成本越高
- **派生**：由其他数值算出

---

## 1. 世俗与宗教（2个）

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **宗教现状指数** | 轴：−100 世俗 ↔ +100 律法 | 婚姻、安息日、饮食、皈依、教育相关法令；联合政府交易 |
| **兵役豁免规模** | 债务 | 每年新增 = 哈雷迪适龄男性 × 豁免覆盖率（杠杆） |

- **世俗阶层的反应**直接体现在共享的**选民集团支持**中，不另设"世俗不满"。
- **哈雷迪人口占比**属于区级人口构成，是共享状态。

**阈值事件**
- 宗教现状指数 ≥ +40：世俗抗议政党崛起；≥ +60：人才外流修正器。
- 兵役豁免规模超过临界值：最高法院介入（需要司法独立度足够高），触发联合政府危机。

**杠杆**：现状协议的各项条款、豁免覆盖率、宗教预算、哈雷迪职业教育计划。

---

## 2. 族群与移民整合（每个群体2个）

**群体**：米兹拉希、俄裔（1990年后）、埃塞俄比亚裔。阿什肯纳兹人是参照基准，不单独计算。

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **疏离度** | 存量 | 安置质量、任命构成、贫富差距、在野党煽动 |
| **历史怨气** | 债务（衰减极慢） | 疏离度长期偏高时累积；即使政策改善，也会持续影响投票 |

**疏离度每月变化（示意）**
```
Δ = 0.4 × 本群体住在过渡营地的比例(%)
  + 0.05 × 任命构成偏差          // 由玩家当前任命实时计算，不单独存储
  + 0.03 × 贫富差距
  − 本群体聚居区的投资效果
  + 在野党煽动强度
  ± 事件修正
```

**阈值事件**
- 疏离度 ≥ 40：地方骚乱；≥ 60：社会抗议运动。
- 历史怨气 ≥ 70：该群体整体倒向反对派（1977年式"政治地震"）。
- 俄裔疏离度 ≥ 50：俄裔自建政党。

**杠杆**：各区安置政策、发展城镇投资、任命的多元化、文化政策。

---

## 3. 犹太国家与阿拉伯公民（每个群体2个）

**群体**：阿拉伯人（穆斯林与基督徒）、德鲁兹人、贝都因人。

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **国家认同度** | 存量 | 平等程度、军事管制（杠杆）、兵役（德鲁兹）、象征性立法、外部冲突 |
| **土地怨气** | 债务 | 征地政策、拆除房屋、未被承认的村庄 |

- "巴勒斯坦认同"用**国家认同度的反面**表示，不另设参数。
- 军事管制强度是**政策杠杆**。

**阈值事件**
- 土地怨气高，同时国家认同度低：大罢工与冲突（1976年"土地日"式）。
- 国家认同度 < 30，同时发生外部战争：混居城市的内部骚乱。
- 德鲁兹国家认同度骤降：触发"血盟破裂"事件。

**杠杆**：军事管制、土地法、预算倾斜、象征性法律、阿拉伯政党入阁、差异化政策。

---

## 4. 大国依赖与战略自主（全国2个，加上每个外部势力1–2个）

**全国参数**

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **战略依赖度** | 派生 | 援助占国防预算的比例、武器来源集中度 |
| **国际合法性** | 存量 | 军事行动、占领、民主形象 |

**外部势力参数**

| 势力 | 参数 |
|---|---|
| 美国 | **政府关系**、**国会关系**（2个；国会可以抵消政府的不满） |
| 法国、苏联、英国、西德 | **关系值**（各1个，按时代开启） |
| 海外犹太社群 | **关系值**（1个，影响捐款、游说、回归移民） |

**阈值事件**
- 政府关系 < 30：援助暂停或最后通牒（可类比1956年艾森豪威尔的施压、1991年老布什冻结贷款担保）。
- 国际合法性 < 30：武器禁运风险。
- 战略依赖度 > 70：盟友施压的效果翻倍。

**杠杆**：武器采购多元化、国产军工、游说、秘密外交、核计划。

---

## 5. 领土与定居（2个）

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **三难三角** | 派生（三个顶点合成一个图形） | 吞并范围、定居规模、公民权政策、人口变化 |
| **定居者运动动量** | 存量 | 政府支持、宗教犹太复国主义者的实力、战争结果 |

- 各区的**定居人口**是区级人口构成，是共享状态。
- **撤离成本**由定居人口和动量实时计算。
- **定居者运动动量**高时，它会成为半自治的行动者，自行建立前哨。

**阈值事件**
- 动量 ≥ 70：定居者自主建点事件频繁出现。
- 动量高时推行撤离：暴力抵抗，极右翼刺杀风险上升。
- 三角严重偏向领土控制，同时民主合法性顶点 < 30：国际上出现"种族隔离"指控。

**杠杆**：区级定居点政策、地点决策（建立、撤离、吞并）、对前哨的执法、规划图。

---

## 6. 经济意识形态（3个：2个全国参数，加上工会这个势力1个）

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **经济模式** | 轴：−100 集体与国有 ↔ +100 市场 | 私有化、国企政策、税制、劳动法 |
| **贫富差距** | 存量 | 经济模式、福利政策、通胀 |
| **工会实力**（势力） | 存量 | 劳动法、国企规模；**同时是劳工党的选举机器** |

- 住房危机、财阀垄断、科技繁荣都用**修正器和事件**表示，由经济模式和贫富差距触发。
- 通胀、增长、财政是共享状态。

**阈值事件**
- 贫富差距 ≥ 60：各群体疏离度加速增长；同时住房压力过大时，触发帐篷抗议式事件。
- 工会实力 < 30：劳工派的动员能力下降；如果此时经济模式偏向集体主义，触发"总罢工"式对抗。

---

## 7. 安全与民主法治（2个，后期开启第3个）

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **民主法治指数** | 存量 | 紧急措施、审查、行政拘留、法官任命、政府是否服从裁决 |
| **公众安全感** | 存量 | 恐袭、战争、威慑值 |
| **司法冲突度**（1990年代以后开启） | 存量 | 法院撤销法律、政府推动司法改革 |

**阈值事件**
- 公众安全感 < 30：获得"要求强硬"修正器，政治整体右移。
- 民主法治指数 < 40：美国国会和欧洲关注，国际合法性下降。
- 司法冲突度 ≥ 70：宪政危机，包括大规模抗议、预备役拒绝服役、资本外逃。

**杠杆**：紧急条例、审查、行政拘留、法官任命、基本法立法、是否设立调查委员会。

## 8. 外部冲突与敌意管理

### 8.1 阿拉伯国家（每国3个）

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **政权敌意** | 存量 | 谈判、秘密渠道、共同敌人、领土 |
| **民间敌意** | 存量 | 巴勒斯坦事件、圣地冲突、伤亡画面 |
| **政权稳定度** | 存量 | 国内经济、民间敌意、大国支持 |

开战概率（派生） = f（政权敌意，民间敌意 × (1 − 稳定度)，−威慑值，大国支持）

### 8.2 巴勒斯坦

**整体（2个）**

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **民间敌意** | 存量 | 占领措施、定居点、伤亡、谈判成果 |
| **生活水平** | 存量 | 经济许可、封锁、援助 |

**每个派系（2个）**

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **实力** | 存量 | 组织、资金、外部庇护者、以色列的打击 |
| **合法性** | 存量 | 成果、殉道者效应、合作者污名 |

- **温和度**、**外部庇护者**是派系的固定属性，不是参数。
- **起义风险**由整体的两个参数实时计算。

### 8.3 全局（2个）

| 参数 | 类型 | 主要驱动 |
|---|---|---|
| **威慑值** | 存量 | 军事行动、战争结果、核能力 |
| **战略自满度** | 隐藏存量 | 长期和平、技术优势、情报机构的判断惯性 |

**力度权衡（示意）**
```
威慑增益   = a × x × (1 − 当前威慑/100)     // 边际递减
民间敌意增量 = b × x²                         // 加速上升
```

**阈值事件**
- 某国民间敌意高，同时政权稳定度低：该国政权被迫开战，或发生政变。
- 战略自满度高：遭受突袭的概率上升。
- 巴勒斯坦起义风险超过阈值：大起义。

## 9. 参数总表

| 矛盾 | 参数 | 数量 |
|---|---|---|
| 1 世俗与宗教 | 宗教现状指数、兵役豁免规模 | 2 |
| 2 族群与移民 | 每个群体：疏离度、历史怨气 | 2 × 3个群体 |
| 3 阿拉伯公民 | 每个群体：国家认同度、土地怨气 | 2 × 3个群体 |
| 4 大国依赖 | 战略依赖度、国际合法性；美国2个，其他势力各1个 | 2 + 每个势力1–2 |
| 5 领土与定居 | 三难三角、定居者运动动量 | 2 |
| 6 经济意识形态 | 经济模式、贫富差距、工会实力 | 3 |
| 7 安全与法治 | 民主法治指数、公众安全感（后期加司法冲突度） | 2–3 |
| 8 外部冲突 | 每个阿拉伯国家3个；巴勒斯坦整体2个、每个派系2个；全局2个 | 按对象计算 |

## 10. 被删除参数的去向

| 原参数 | 去向 |
|---|---|
| 世俗不满 | 并入共享的选民集团支持 |
| 哈雷迪人口占比、劳动参与率 | 区级人口构成（共享状态）和经济修正器 |
| 宗教阵营关系 | 体现在两个宗教政党的盟党满意度中 |
| 融合度 | 用疏离度的反面表示 |
| 精英垄断度 | 改为由当前任命实时计算的"任命构成偏差" |
| 安置质量、中心与边缘差距 | 区级发展水平（共享状态） |
| 军事管制强度 | 政策杠杆 |
| 巴勒斯坦认同 | 用国家认同度的反面表示 |
| 犹太公众的不信任 | 并入公众安全感 |
| 援助流量 | 财政的收入项 |
| 主权敏感度 | 改为修正器："向盟友让步"时触发右翼反弹 |
| 非法前哨、撤离阻力 | 实时计算，由定居人口和动量决定 |
| 公众领土立场 | 由选民集团构成汇总得出 |
| 国家暴力垄断度 | 改为1948年开局专属的事件链和修正器 |
| 集体部门活力、住房压力、财阀集中度、科技部门规模 | 由经济模式和贫富差距触发的修正器与事件 |
| 司法独立、新闻自由、紧急权力 | 合并进民主法治指数 |
| 制度信任、军方政治影响 | 改为人物和事件层面的效果 |
| 威慑感知（逐国） | 并入全局威慑值，各国可以有修正 |
| 情报准确度 | 改为情报首长的人物属性 |
| 圣地张力 | 改为由宗教现状指数和民间敌意触发的事件链 |
| 海外犹太人模块 | 并入大国依赖模块，作为一个外部势力 |
| 资源、记忆与认同模块 | 删除，改为区级属性、修正器和历史事件 |
