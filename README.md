# 以色列政治策略游戏（设计阶段）

一款以以色列（1948年至今）为背景的硬核政治策略游戏。第一阶段采用剧本制：玩家扮演一位已去世的真实历史总理，从就任开始，在以天为单位推进的连续时间里，一方面兑现承诺、守住党的立场，一方面推动以色列走向自己想要的方向。同时还要平衡这个国家的结构性矛盾：世俗与宗教、族群分化、犹太国家与阿拉伯公民、大国依赖与战略自主、领土与定居、经济意识形态、安全与民主法治，以及外部冲突。
