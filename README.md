# 以色列政治策略游戏（设计阶段）

一款以以色列（1948年至今）为背景的硬核政治策略游戏。玩家扮演一位虚构的以色列政治人物，从部长起步，在以天为单位推进的连续时间里，平衡这个国家的结构性矛盾：世俗与宗教、族群分化、犹太国家与阿拉伯公民、大国依赖与战略自主、领土与定居、经济意识形态、安全与民主法治，以及外部冲突。
